# CLI 交卷驱动 TaskType 与 DAG

承接 SPEC R04–R11、R12、R17。CLI 通过本次执行凭据汇报并绑定实际报告，拒绝过期身份与错误路径。有效报告与正常 turn 结束齐备后按 TaskType 推进；有审查时必须通过当前候选。finish 将固定候选放入 Engine 拥有的交付队列，成功集成后才完成 Task 并放行下游。返修与补报复用 session，循环有限。每 Graph 串行集成，等待交付不占 Agent 并发名额，失败项不阻止独立项。

验收使用受控 runtime 与真实存储、Git，观察早报不提前推进、重复交卷不重复快照、漏报原会话补跑、异常结束不冒充漏报、返修原 thread、所有前置发布后才启动下游，以及同时完成时的串行发布。冲突、验证失败、暂停、中断、重启和显式恢复不能提前放行下游或重复发布。追加屏障 queued 与交付队列 merge_queued 分开。保留 Mailbox、输入接收和 Agentic 子会话门禁，CLI 子进程覆盖端到端交卷。输入：[实施规格](../SPEC.md)、已交付运行时和 Git 接口。
