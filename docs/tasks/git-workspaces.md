# 隔离代码成果与自动 Git 快照

承接 SPEC R10、R11。每个 Graph 首次运行固定项目 HEAD，建立集成分支。Task 启动前固定当前集成提交，并从该精确提交创建独立 worktree，不另合并依赖列表。自动快照生成固定候选，交付在隔离工作区合并并验证实际结果，通过后原子推进 Graph 分支与发布回执。全部 Task 集成后无需整图最终合并。参数使用 spawn argv，不拼 shell。报告路径与运行元数据不进入代码快照。

验收使用真实临时仓库，覆盖固定起点、独立成果进入后续起点、活动工作区不漂移、并行候选串行集成、冲突与验证失败不发布、独立候选继续、幂等重试及空改动交付。验证源候选和实际集成提交分别记录，项目原分支与目录不变。验证命令改变 HEAD 或代码时拒绝发布。Graph 镜像未同步时保留外部改动并给出警告。只在托管目录操作，不自动清除冲突或丢弃用户改动。输入：[架构与接口](../architecture.md)、`src/shared/types.ts`。
