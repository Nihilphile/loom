# CLI 交卷驱动 TaskType 与 DAG

承接 SPEC R04–R09、R11。CLI 通过本次执行凭据向服务汇报、绑定真实报告，拒绝过期身份与错误路径；与正常 turn 结束共同满足后才调度。TaskType 规则为数据，默认无审查直接交付、有审查必须通过。返修/补报复用 session，循环有限，真实 Git 快照与依赖结果推进 DAG。

验收：受控 runtime + 真实存储/Git，分别观察早报不提前调度、重复交卷不重复快照、正常漏报补跑、崩溃不冒充漏报、两轮 review 使用原 thread、多依赖与独立分支、最终汇总。CLI 子进程端到端交卷。输入：SPEC、已交付运行时和 Git 接口。
